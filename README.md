# Explainable AI

A portfolio of Explainable AI projects focused on understanding, interpreting, and evaluating machine learning models.

## Overview

This repository contains selected Explainable AI projects developed during my Master's studies in Artificial Intelligence at Johannes Kepler University Linz (JKU).

The projects explore different approaches for understanding machine learning models, including global feature importance, local explanations, model behavior, dimensionality reduction, and other interpretability techniques.

## Projects

### 01. California Housing — Model Explanations

An Explainable AI project using an XGBoost regression model trained on the California Housing dataset.

The project applies several complementary explanation techniques:

- Permutation Feature Importance
- SHAP (SHapley Additive exPlanations)
- Partial Dependence Plots (PDP)
- Individual Conditional Expectation (ICE)
- Counterfactual Explanations using DiCE

The analysis investigates global feature importance, local prediction explanations, non-linear feature effects, and counterfactual explanations.

**Folder:** `01-california-housing-xai/`

### 02. Global Salary Analysis

This project investigates a large-scale global salary dataset using machine learning and dimensionality reduction techniques.

The analysis includes:

- Data preprocessing
- Principal Component Analysis (PCA)
- t-SNE
- UMAP
- HDBSCAN clustering
- Quantitative evaluation of dimensionality reduction
- Trustworthiness
- Continuity
- kNN-Overlap

**Folder:** `02-global-salary-analysis/`
